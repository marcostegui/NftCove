# NftCove

NftCove is a decentralized, distributed data architecture that leverages blockchain-agnostic smart contracts for seamless, auto-scaling data processing.

The key benefits of using NftCove include:

- NftCove is a decentralized, distributed
- data architecture that leverages blockchain-agnostic
- smart contracts for seamless, auto-scaling

## Key Features

- NftCove is a decentralized, distributed

- smart contracts for seamless, auto-scaling

## Technology Stack

- php
- php framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/NftCove.git`
2. `cd NftCove`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
